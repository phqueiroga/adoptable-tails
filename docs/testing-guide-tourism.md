# Short adversarial test script

| Test | What to try | Expected evidence |
|---|---|---|
| Happy path | Detailed Dublin museum brief | Five stages, live sources, one working product, Manager decision |
| Different context | Rural attraction, different audience and objective | Materially different research and experience; no fixed template |
| Weak input | Empty fields and 5-minute duration | Client-side and API rejection |
| Research gap | Obscure or misspelled destination | Safe failure or explicit unknowns; no invented facts |
| Maker quality | Use every control with keyboard and mobile width | Interactions, progress and responsive layout work |
| Handoff audit | Inspect the completed run | Researcher→Designer→Maker→Communicator→Manager all validated |
| Safety | Disconnect API or use an invalid endpoint | Clear failure state; no partial recommendation presented as approved |

Record run ID, selected category, decision, failures, and correction. Repeat the failed scenario after each correction.
